# XJTU 研究生课程规划助手

面向西安交通大学研究生的本地课程规划网页。它可在课程目录中检索课程、建立培养方案与课组、自由安排到 0–18 周课表，并检查时间冲突。

课程信息仅供参考，请以教务系统最新信息为准。

## 快速开始

需要安装 Node.js（建议 18 LTS）和 npm。

```bash
npm install
npm run serve
```

浏览器打开 [http://localhost:8080/](http://localhost:8080/)。页面会按窗口宽度自动显示桌面版或手机版。

生产构建：

```bash
npm run build
```

## 使用方法

### 1. 检索并加入培养方案

1. 在“课程检索”中按课程号、课程名称、班级、学院、校区、教师或上课时间筛选。
2. 点击课程卡片的“加入方案”。课程会进入“培养方案”，此时尚未排入课表。
3. 在“培养方案”中点击课程卡片，即可加入或移出左侧周课表。
4. 同一课程号只能选择一个班；如需换班，请先从课表中移出已选班级。

### 2. 管理课组

- 可新建外语课组、公共课组、专业课组、选修课组或必修环节。
- 设置每个小组应选的门数或学分后，课程可通过“加入组”归入对应小组。
- 小组中的“已选”仅统计已加入课表的课程；超出限制会以红色提示。
- 可展开/关闭课组、拖动课组标题调整顺序，或删除不再需要的小组。

### 3. 查看课表与处理冲突

- 顶部滑块可切换第 1–18 周；“我的课表”相当于第 0 周，汇总所有已上课表课程。
- 课表支持普通显示与合并显示两种布局。
- 鼠标悬停课程可查看课程号、完整课程名、班级、教师和地点；点击课程会定位到培养方案中的对应课程。
- 出现冲突时，“冲突课程”栏会标记相关周次。点击冲突项后，可保留一门课程并移出其余课程。
- 没有上课时间或无法放入当前课表布局的课程会显示在“待安排课程”表中。

### 4. 导入

点击顶部“导入…”按钮后选择导入内容。

#### 导入课程目录

用于覆盖当前课程检索数据。按页面提示从教务系统课程目录下载 `.mhtml` 文件，再在弹窗中选择该文件读取。

#### 导入培养方案

先选择上课校区，再根据弹窗提示登录教务系统并保存个人培养计划页面为 `.mhtml` 文件。选择该文件后，系统会：

- 仅读取培养计划中已勾选的课程；
- 按外语课、公共课、专业学位课、选修课、必修环节创建课组；
- 根据组内“选 N 门/分”要求创建对应的小组限制；
- 在本地课程目录中查找课程号，并提示未找到排课信息的课程。

建议导入后认真核对课程、班级、校区与课组要求。

### 5. 导出

点击顶部“导出为…”按钮：

- **导出课程表 CSV**：生成 WakeUp 课程表软件可读取的七列表格。若存在未解决冲突，或课程缺少上课时间，会先提示处理。
- **导出为排课单**：生成当前已上课表课程的 CSV，包含课组序号、课组类型、课程号、课程名称、班级、教师、上课时间、地点和学分。课程号按 Excel 文本格式写出，以保留前导零。

## 课程数据

默认课程数据来自项目根目录的 `lecture_unite.csv`。开发或部署时，该文件会复制到网页静态资源中并自动加载。
